Создай модели и а к ним миграции, сиды и контроллеры для следующих сущьностей:

## Сущьность - Эмиссионные документы

**Необходимые поля:**

- Заголовок (строковое, 700 символов)
- Краткое описание (текстовое nullable)
- Файл (строковое, 700 символов)
- Порядок вывода (Целочисленное по умолчанию 100)

## Сущьность - Наши проекты

**Необходимые поля:**

- Заголовок (строковое, 700 символов)
- Слаг (строковое, 700 символов)
- Изображение (строковое, 700 символов, nullable)
- Краткое описание (текстовое nullable)
- Галерея (json nullable)

## Сущьность - Новости и события

**Необходимые поля:**

- Заголовок (строковое, 700 символов)
- Слаг (строковое, 700 символов)
- Изображение (строковое, 700 символов, nullable)
- Краткое описание (текстовое nullable)

## Сущьность - Товары и услуги

**Необходимые поля:**

- Заголовок (строковое, 700 символов)
- Слаг (строковое, 700 символов)
- Изображение (строковое, 700 символов, nullable)
- Краткое описание (текстовое nullable)

Для каждой из этих сущьностей создай по 2 роута один для вывода основного раздела другой для вывода отдельной страницы сущьности. Исключение сущьность 'Эмиссионные документы' для нее создай только роут основного раздела. Роуты размести в файле routes/asmi_all.php

Для каждлшл роута создай блейд шаблон. Для шаблонов по сущьностям создай отдельные папки в resources/views.

Внутрь каждого шаблона помести код:

```php

@extends('layouts.all')

@section('main')
    <section class="section-header">
        <div class="container">
            <h1 class="section-header__title"></h1>
        </div>
        <div class="shadow"></div>
    </section>

    <section class="breadcrumbs_section">
        <div class="container">
            <x-breadcrumbs.main title=""></x-breadcrumbs.main>
        </div>
    </section>

    <section class="page page_section">
        <div class="container">

        </div>
    </section>
@endsection

```
