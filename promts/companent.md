# Компонент для отображения документов

Создай компонент для отображения сущьности описанной моделью EmissionDocument.

## Входные данные

В компонент на вход поступает элемент модели EmissionDocument

## Стилизация компонента

Компонент представляет собой блок который разделен на следующие части:

- Заголовок
- Описание (если имеется)
- Кнопка - Скачать

Все эти элементы расположенны в столбик. В низу блока бордер в 1 пиксель цвета $gray_border_color

Стили размести в public/scss/\_emission-documents.scss

## Вывод компонета

Данный компонет будет выводится в цикле в шаблоне resources/views/emission-documents/index.blade.php

# Компонент для отображения новостей и событий

Создай компонент для отображения сущьности описанной моделью NewsEvent.

## Входные данные

В компонент на вход поступает элемент модели NewsEvent

## Стилизация компонента

Компонент представляет собой карточку в которой в столбик будут расположенны следующие элементы:

- Изображение
- Заголовок
- краткое описание
- кнопка с текстом - Подробнее...

Карточка занимает всю ширину обертки, тоесть одна в ряд. В левой части карточки расположено фото, в правой блок с текстом в котором в свою очередь выводятся остальные элементы. Заголовок должен быть жирным и обернутым в h3.

На мобильных устройствах изображение должно быть в верхней части.

Стили размести в public/scss/\_projects.scss

## Вывод компонета

Данный компонет будет выводится в цикле в шаблоне resources/views/projects/index.blade.php

# Компонент для отображения услсг

Создай компонент для отображения сущьности описанной моделью ProductService.

## Входные данные

В компонент на вход поступает элемент модели ProductService
